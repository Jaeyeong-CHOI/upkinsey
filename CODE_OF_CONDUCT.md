# Community Code of Conduct

한국어와 영어로 참여할 수 있습니다. 배경, 경험, 국적, 성별, 장애 여부와 관계없이 서로 존중하며, 사람 대신 제안과 코드에 대해 토론해 주세요.

Upkinsey welcomes participants of all backgrounds and experience levels. This policy applies to project issues, pull requests, reviews, and other spaces explicitly operated for the project.

## Expected behavior

- Be considerate, give actionable feedback, and acknowledge mistakes.
- Critique ideas and code, not people; allow good-faith disagreement.
- Respect privacy, consent, and contributors' time.
- Do not engage in harassment, threats, hate speech, sexualized attention, impersonation, doxxing, spam, or retaliation against a reporter.

## Reporting and moderation

For conduct in project spaces, the responsible maintainer is [@Jaeyeong-CHOI](https://github.com/Jaeyeong-CHOI). If a private contact method is listed on that public profile, use it. If none is available, open an issue titled **Private conduct contact requested** and mention the maintainer, without names, allegations, screenshots, or other incident details. The maintainer should establish a private reporting route before requesting those details. A GitHub mention is public, not a private message.

For abuse on GitHub, or a report involving the repository owner where this project cannot offer independent review, use [GitHub's reporting process](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam). It is a platform escalation path, not a promise that GitHub will adjudicate this project's policy.

Share incident links, approximate dates, and the minimum context needed for review through the agreed route. Maintainers should limit disclosure to what is necessary to address the incident and explain any necessary disclosure; absolute confidentiality cannot be guaranteed.

Depending on severity and repetition, maintainers may request a correction, warn a participant, remove content, restrict participation, or ban access. They should explain the reason and scope privately where practical. Requests for reconsideration may use the same reporting route and should add relevant context. This small project has no independent conduct committee or guaranteed response time.
